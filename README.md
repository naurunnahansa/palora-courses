# Palora Courses

Course content repository for the Palora learning platform.

## Structure

```
{category}/
  {course-slug}/
    _course.json       # Course metadata
    content/
      {unit}/
        {page}.json    # Page content
    quizzes/
      {quiz}.json      # Quiz content
    visualizations/
      {viz}.html       # Interactive visualizations
      _index.json      # Visualization index
```

- biology
